# Runner Resume Fixes - 40-Pass Review Update

Date: 2026-06-08

Additional fixes after the 40-pass review request:

1. Candidate workspace construction now always seeds from the canonical workspace first, then overlays the richest prior same-task attempt/snapshot. This prevents old `.attempts` deltas from erasing T1/T2 dependencies when resuming T3/T4.
2. Resume repair now uses a strict all-expected-files check instead of an any-file check. This prevents `README.md` alone from making a done task look fully repaired.
3. Deferred-evidence QA override now requires the full expected scope to exist before converting an evidence-only block into a done result.
4. QA evidence-only detection is now conservative and refuses to waive blocks that include structured code/API defects.
5. Candidate workspace promotion now uses a temp copy plus backup/rollback path and safe filesystem tokens.
6. Root-level local scratch files were removed from the patched package.
7. Added `self_review_40_deep_checks_20260608.py` with 40 executable checks covering syntax, scope, directives, QA waiver behavior, candidate snapshots, repair, promotion, and package hygiene.
